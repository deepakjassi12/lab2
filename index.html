Learn to code, one small step at a time.

Deepak Learn to Code is a beginner-friendly series that takes you from writing your very first line of HTML to building and publishing your own website. Each lesson is short, practical, and ends with something you can actually open in your browser. No prior experience needed, just a laptop, a text editor, and some curiosity.

Part 1: HTML Foundations

Learn how web pages are structured using headings, paragraphs, links, images, and semantic tags like header, main, and footer.

Project: build a personal "About Me" page

Part 2: Styling with CSS

Add colour, fonts, and spacing to your pages, then use Flexbox and media queries to make layouts that work on phones and desktops.

Project: a responsive profile card layout

Part 3: JavaScript Basics

Make your pages interactive with variables, functions, and events, then publish your finished site for free with GitHub Pages.

Project: an interactive to-do list
